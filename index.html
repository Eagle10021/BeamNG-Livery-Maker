    Choose a template

    Templates from the "Skin Helper" mod by Beamer XD. Newer vehicles: use the BeamNG install tab, which reads the game's own UV templates.

    Pick a vehicle's .zip from your game folder: BeamNG.drive/content/vehicles/. Nothing is uploaded; the file is read in this browser.

    Export skin

    The .dds is lossless and large. BeamNG loads it as it is; to make it smaller, convert it to BC7 in a tool such as Paint.NET, texconv or Photopea. See the guide for the mod's folders and files.
